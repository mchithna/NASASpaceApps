# InSight

Story title: The Machine That Listened to Mars.

This folder is the InSight chapter package. The story, scenes, and activities are not written yet. Edit `mission.ts` for metadata. The shared registry imports this package, so titles and descriptions do not belong in a central list.

## Assets

Mission media lives in `public/assets/missions/insight/`.

- `cover.svg` is the cover referenced by `coverImage`. It is a generated placeholder, not a NASA photograph.
- Later files use lowercase kebab-case names, for example `surface-view.jpg`.
- Do not add NASA logos, flags, or mission insignia. Add a real NASA image only after it is approved, and keep its credit in `mission.ts`.
