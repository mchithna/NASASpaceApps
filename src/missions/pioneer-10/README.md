# Pioneer 10

Story title: The Messenger That Never Came Home.

This folder is the Pioneer 10 chapter package. The story, scenes, and activities are not written yet. Edit `mission.ts` for metadata. The shared registry imports this package, so titles and descriptions do not belong in a central list.

## Assets

Mission media lives in `public/assets/missions/pioneer-10/`.

- `cover.svg` is the cover referenced by `coverImage`. It is a generated placeholder, not a NASA photograph.
- Later files use lowercase kebab-case names, for example `surface-view.jpg`.
- Do not add NASA logos, flags, or mission insignia. Add a real NASA image only after it is approved, and keep its credit in `mission.ts`.
